# Excel Data Analysis Project

## Project Overview
This project focuses on analyzing Superstore sales data using Microsoft Excel to identify key business metrics and understand sales and profit performance.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data filtering and formatting

## Key Tasks Performed
- Analyzed sales, profit, and quantity data.
- Calculated key performance indicators (KPIs).
- Created PivotTables for category-wise, region-wise, and profit analysis.
- Analyzed monthly sales trends.
- Created charts to visualize regional sales performance.
- Prepared a summary sheet highlighting important business metrics.

## Key Performance Indicators
- **Total Sales:** 2,297,200.86
- **Total Profit:** 286,397.02
- **Total Quantity Sold:** 37,873
- **Average Sales per Order Row:** 229.86
- **Profit Margin:** 12.47%

## Key Insights
- Compared sales performance across different regions.
- Examined profit performance to understand business profitability.
- Organized key metrics into a summary sheet for quick reference.
- Used charts and PivotTables to make the data easier to interpret.

## Project Outcome
This project strengthened my practical skills in Excel-based data analysis, KPI calculation, data summarization, and data visualization.
